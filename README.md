# Test Maestro/a Albañil — GitHub Pages

## Publicación
1. Descomprime este ZIP.
2. Sube **el contenido** de la carpeta (no la carpeta contenedora) a la raíz del repositorio `joliveraton.github.io`.
3. Haz commit.
4. En GitHub: **Settings → Pages → Build and deployment → Deploy from a branch → main / root**.
5. Espera el despliegue y abre `https://joliveraton.github.io/`.

## Uso
- Filtra por examen o categoría.
- Responde y pulsa **Validar respuesta**.
- Si fallas, se muestra la opción correcta.
- Las estadísticas y el progreso se guardan localmente en el navegador.

## Archivos
- `preguntas.js`: banco de preguntas.
- `app.js`: lógica del test.
- `style.css`: diseño.
- `index.html`: página principal.

El banco se reutiliza del proyecto previo generado a partir del PDF aportado en esta conversación. Conviene revisar visualmente las preguntas que procedan de páginas con extracción OCR defectuosa antes de considerar el banco como edición final.
